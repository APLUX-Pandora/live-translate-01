# Licensing scope

The Live Translate application, example code and documentation use Apache-2.0.
See [LICENSE](LICENSE) and [NOTICE](NOTICE).

The Demo obtains both component SDKs through its Git submodules. Follow the
[installation instructions](README.md#1-install) to install them with the Demo.
Preserve their license files, supplier notices and package metadata if
redistributing the SDKs. The component publishers supply the software and the
licenses for their native code, bundled runtimes and dependencies.

Download model packages separately from their respective repositories and keep
the licenses and notices in each package. The built-in lecture, poster and upload
example include excerpts from a FOSDEM recording under CC BY 2.0 BE.
See [media attribution](docs/MEDIA_ATTRIBUTION.md).
